## New here? Start with these

<Steps>

1. **[Install it](/self-hosting/installation/).** One `docker-compose.yml`, a four-line `.env`
   and `docker compose up -d`. A small VPS, a NAS or a Raspberry Pi is enough.

2. **[Add HTTPS](/self-hosting/https/).** Put your own domain in front so guests and staff
   connect securely.

3. **[Connect email](/self-hosting/email/).** Optional, but guests get a confirmation with a
   link back to their booking.

4. **[Schedule backups](/self-hosting/backup-restore/).** Everything lives in two Docker
   volumes, and one command saves both.

</Steps>
