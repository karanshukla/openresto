## Getting started

<Steps>

1. **[Install with Docker](/self-hosting/installation/).** Download `docker-compose.yml`, create a four-line `.env` file, and run `docker compose up -d`. A small VPS, NAS, or Raspberry Pi is enough.

2. **[Add HTTPS](/self-hosting/https/).** Put your domain in front of OpenResto so guests and staff connect over TLS.

3. **[Connect email](/self-hosting/email/).** Optional. Send guests booking confirmations with a link back to their reservation.

4. **[Schedule backups](/self-hosting/backup-restore/).** All persistent data lives in two Docker volumes, and a single command backs up both.

</Steps>
